# SensorScope

SensorScope is an open-source Android application that lets users discover the sensors available on their device and view their readings in real time.

It uses Android's native Sensor Framework to provide direct access to sensor data such as accelerometer, gyroscope, magnetometer, light, and proximity readings. The project starts with sensor discovery and live readings, with scope to later add graphs, visualizations, experiments, calibration, and data export.

## Tech Stack

- Kotlin
- Jetpack Compose (Material 3)
- Android Sensor Framework (SensorManager, Sensor, SensorEventListener)
- Kotlin Coroutines and Flow

## Getting Started

1. Clone the repository:

    git clone https://github.com/GFG-OS-MANAGEMENT/SensorScope.git
    cd SensorScope

2. Open the project in Android Studio.
3. Let Gradle sync and run the app on a physical device or emulator.
