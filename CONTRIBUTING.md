# Contributing to SensorScope

## Workflow

1. Check the Issues tab for open issues labeled GFG-OSC.
2. Comment on the issue to request assignment. Do not open a PR until the issue is assigned to you.
3. A contributor can hold at most 3 assigned issues at a time.
4. Fork the repository and create a branch for your issue:

    git checkout -b fix/issue-<number>

5. Complete only the numbered TODO items in the file mentioned in your issue. Do not modify unrelated files.
6. Commit and push your work, then open a Pull Request referencing Closes #<number>.
